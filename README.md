# 香港智慧城市地圖

打開就是一幅可縮放的香港地圖。底圖用 [OpenFreeMap](https://openfreemap.org/) 的公開服務。地圖上有十條提供實時班次的港鐵路綫，以及運輸署的交通快拍點。

- 點選車站，查看該站即將到站的列車、目的地、月台和大約幾分鐘。
- 點選橙色快拍點，查看該路段的最新照片。
- 暫時沒有班次或照片時，側欄會直接寫明原因。

輕鐵不在這份實時班次資料內，所以沒有畫出。

## 本機運行

需要 Node.js 22。

```bash
npm install
npm run dev
```

瀏覽器打開 [http://127.0.0.1:4731](http://127.0.0.1:4731)。地圖、班次和照片都要能連上外網。

```bash
npm test
npm run build
```

`npm run data` 會再下載快拍位置，並用 `scripts/geocode-cache.json` 裡的車站座標重寫資料檔。座標來自地政總署位置搜尋，已由香港 1980 方格網轉成經緯度。

## 資料怎樣配合

| 內容 | 來源 |
| --- | --- |
| 底圖 | OpenFreeMap Liberty 樣式 |
| 路綫和車站名稱 | 港鐵路線及車站 CSV，支線按行車路徑分開 |
| 車站位置 | 地政總署位置搜尋，建立時寫入項目 |
| 到站班次 | `https://rt.data.gov.hk/v1/transport/mtr/getSchedule.php` |
| 快拍位置 | 運輸署攝影機位置 XML |
| 快拍照片 | `https://tdcctv.data.one.gov.hk/{編號}.JPG` |

班次和照片在你點選時才向官方網址讀取，約十秒內重用同一站的班次結果。位置清單放在網頁裡，因為這兩個檔案不允許瀏覽器跨站直接下載。

東鐵綫的落馬洲和羅湖分開畫。馬場站不在路線 CSV，按實時 API 補上，畫成火炭與大學之間的短支線。將軍澳綫的康城支線另行畫出。路線 CSV 把荔景、荔枝角寫成異體字「茘」，畫面上改為常用的「荔」。

快拍位置檔有兩筆網址對調（AID09104、AID09206）。照片裡印著的編號和方向與檔名一致，所以程式按編號取圖。

## 出處

底圖由 OpenFreeMap 提供，地圖資料來自 OpenMapTiles 與 OpenStreetMap。到站班次的知識產權屬香港鐵路有限公司，交通快拍屬香港特別行政區政府，經 DATA.GOV.HK 發放。使用這些資料須注明來源，不得把下載的資料本身轉售。

## 日後發佈

這份預覽尚未發佈。驗收後才放到 Cloudflare Workers 免費方案，使用帳戶的 `workers.dev` 網址，不開自訂網域，也不使用 KV、D1 或 R2。

網頁是靜態檔。靜態檔的讀取不計入每日程式請求，也不另收費。班次和照片由瀏覽器直接向官方網址讀取。按這個做法，預計費用是 **0 元**。免費方案每日 100,000 次程式請求，超出時會拒絕請求，不會自動改為付費。Workers 付費方案要另外開通，由每月 5 美元起，課堂演示不需要。

發佈前先 `npm run build`，再以 Wrangler 4 部署 `dist`：

```bash
npx wrangler login
npx wrangler deploy
```

這要用你的 Cloudflare 免費帳戶登入一次。`workers.dev` 網址預設是公開的。
